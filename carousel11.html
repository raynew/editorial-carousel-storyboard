Instagram does not let a webpage drop files straight onto a personal feed. On a phone, Share to Instagram hands the rendered slides to the Instagram app. Direct posting needs a Professional account and Meta’s publishing API (settings below). Local download stays available.

Meta API settings (optional)

Required for Publish via Meta API: Instagram Professional account linked to a Facebook Page, a Meta app with content publish permission, a long-lived user token, and a public image host. Meta fetches each slide from a public HTTPS URL — it cannot use files that only exist on your computer. Tokens are stored only in this browser.
